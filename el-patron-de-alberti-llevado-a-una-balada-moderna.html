🎹 El patrón de Alberti llevado a una balada moderna

Un patrón nacido en la música clásica puede convertirse en una herramienta muy útil para acompañar una balada moderna.

🎯 Qué vamos a aprender

Vamos a utilizar el patrón:

C(I) → G(V) → E(III) → G(V)

La idea fundamental es que, en lugar de tocar las tres notas de un acorde simultáneamente, las convertimos en un movimiento continuo.

1. El acorde de C mayor

Primero entendamos el acorde.

El acorde de C mayor está formado por:

C(I) — E(III) — G(V)

C(I) es la fundamental.
E(III) es la tercera.
G(V) es la quinta.

2. Convertimos el acorde en un patrón

Ahora reorganizamos las tres notas de esta manera:

C(I) → G(V) → E(III) → G(V)

Este movimiento se repite continuamente.

🎵 Resultado musical

Pulsa "Reproducir"

3. ¿Qué está haciendo realmente la mano?

Paso 1

Toca C(I) con el dedo 5.

Paso 2

Salta a G(V) con el dedo 2.

Paso 3

Baja a E(III) con el dedo 1.

Paso 4

Regresa a G(V) con el dedo 2.

4. El teclado

C(I)
D(II)
E(III)
F(IV)
G(V)
A(VI)
B(VII)

5. Ahora lo convertimos en música moderna

Supongamos que nuestra progresión armónica es:

C(I) → Am(VI) → F(IV) → G(V)

Podemos utilizar un patrón semejante en cada acorde.

C(I)

C(I) → G(V) → E(III) → G(V)

Am(VI)

A(VI) → E(III) → C(I) → E(III)

F(IV)

F(IV) → C(I) → A(VI) → C(I)

G(V)

G(V) → D(II) → B(VII) → D(II)

6. La progresión completa

C(I) → G(V) → E(III) → G(V)

A(VI) → E(III) → C(I) → E(III)

F(IV) → C(I) → A(VI) → C(I)

G(V) → D(II) → B(VII) → D(II)

7. ¿Por qué funciona?

Aquí aparece una idea muy importante para la composición.

El acorde no tiene que ser tocado siempre como un bloque.

Podemos convertir sus notas en un movimiento melódico.

La mano izquierda deja de ser simplemente:

"tocar acordes"

y empieza a funcionar como una pequeña línea musical.

8. Ejercicio

Nivel 1

Toca solamente:

C(I) → G(V) → E(III) → G(V)

Muy lentamente.

Nivel 2

Mantén un pulso constante.

No aceleres cuando cambias de nota.

Nivel 3

Toca cuatro compases utilizando C(I).

Nivel 4

Cambia a la progresión:

C(I) → Am(VI) → F(IV) → G(V)

🧠 La idea que debes recordar

Un acorde puede convertirse en movimiento.

Esa es una de las claves para transformar patrones clásicos de mano izquierda en acompañamientos modernos.
